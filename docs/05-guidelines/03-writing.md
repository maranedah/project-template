# Writing guidelines

Read this when: writing or editing any doc in this repo.

1. **Fewer words.** If it can be said shorter, say it shorter. Delete throat-clearing.
2. **Document once, link forever.** If a fact is already documented, link it — never
   restate. SSOTs are listed in CLAUDE.md.
3. **Big picture over hyperfocus.** One good explanation of a thing; don't keep
   polishing documented corners while the map has blank areas.
4. **Line budgets**: docs ≤120 lines (lint-enforced), CLAUDE.md ≤70, rules ≤60.
5. Every doc opens with a one-line "Read this when: …" so the router stays cheap.
6. Tables for enumerable facts; prose for reasoning; `<!-- FILL -->` for template slots.
7. Findings cite evidence (commands, numbers); docs cite findings by id (F-NNNN).
